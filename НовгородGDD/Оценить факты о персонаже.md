#Механика 

# Зачем

Получить численную [[Репутация|репутацию]] персонажа B в глазах персонажа A: как A оценивает известные ему факты о B через свои [[Черты характера персонажа|трейты]].

# Условие (When)

По запросу другой механики или системы (например [[Узнать личное отношение]], проверка перед договором в [[Система обещаний]], пересчёт после нового факта).

# Читает (State)

- [[Память (знание о других)]] персонажа A о персонаже B (factId + conf)
- [[Черты характера персонажа]] персонажа A
- [[Факты о персонаже]] (вес факта, знак для трейтов)

# Эффект (Then)

Для каждого известного A факта об B:

1. Взять базовый вес факта из словаря
2. Если у A есть трейт из «положительных» для факта → вклад со знаком «+»
3. Если из «отрицательных» → вклад со знаком «−»
4. Умножить вклад на conf факта
5. Сложить все вклады → число R (репутация B в глазах A)

Пока веса в словаре пустые — R = 0 (заглушка).

# Пишет (State)

— (чистая функция; никуда не сохраняет, возвращает R)

# Пример

A знает об B факт «даёт в долг» (conf 0.8), A щедрый → факт даёт плюс к R. Другой персонаж с трейтом «жадный» на тот же факт получит другой R.
