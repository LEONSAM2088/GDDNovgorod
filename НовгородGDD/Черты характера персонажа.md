#Данные
# Зачем

Черты характера нужны персонажу, чтобы на их основе оценивать факты о других ([[Оценить факты о персонаже]]) и принимать решения (в т.ч. в [[Система обещаний|обещаниях]]).

# Где живёт

У [[Игровой персонаж (Chapter)]] (у NPC обязательно; у игрока — по дизайну, если понадобится те же оценки).

# Схема

```json
{
	"traitList": [traitId, traitId, traitId]
}
```

Ровно 3 трейта; нельзя брать оба из одной противоположной пары — см. [[Черты характера]].
