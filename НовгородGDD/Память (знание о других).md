#Данные
# Зачем

Память нужна персонажам, чтобы хранить знание и факты о другом персонаже и за счёт этого выстраивать взаимодействие (слухи, репутация, отношение).

# Где живёт

У [[Игровой персонаж (Chapter)]] — и у NPC (AI), и у игрока (известные и придуманные факты).

# Схема

```json
{
	"facts": [
		{ "chapterId": int, "factId": int, "conf": float }
	]
}
```

`chapterId` — о ком факт; `factId` — см. [[Факты о персонаже]]; `conf` — уверенность в факте (0…1).
