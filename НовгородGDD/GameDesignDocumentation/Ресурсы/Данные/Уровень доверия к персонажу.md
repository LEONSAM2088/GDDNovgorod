#Данные
# Зачем

Доверие нужно, чтобы получать отсрочку, кредит, союз, голос, веру в слово и в слух — то, чего нельзя купить деньгами сразу. См. также [[Доверие]].

# Где живёт

У [[Игровой персонаж (Chapter)|персонажа]] A — исходящий список: **кому A доверяет**.

# Схема

```json
{
	"trustLevels": [
		{"chapterId": int, "trustLevel": int}
	]
}
```

`trustLevel` у записи с `chapterId = B` = доверие **A → B** (от 0 до 100, по умолчанию 0).

# Словари

**trustLevel**
```sql 
trustLevel >= 0 and trustLevel <= 100, DEFAULT 0, TYPE INT
```

**chapterId** — id персонажа B
