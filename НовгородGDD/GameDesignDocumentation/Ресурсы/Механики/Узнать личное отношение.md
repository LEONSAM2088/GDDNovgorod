#Механика 

# Зачем

Получить значение личного отношения персонажа A к персонажу B (для UI сводки и решений AI).

# Условие (When)

1. Когда игрок выбирает НПС и открывает сводку о нём → считают отношение **НПС (A) к игроку (B)**
2. Когда AI/система запрашивает отношение A к B

# Читает (State)

A — кто относится; B — к кому:

- A → [[Уровень доверия к персонажу]](B)
- A → [[Статус (персонажа)]], B → [[Статус (персонажа)]]
- A → [[Память (знание о других)]](B)
- A → [[Черты характера персонажа]]
- B → [[Возраст персонажа]]
- B → [[Риторика навык]]
- B → [[Благосостояние персонажа]]

# Эффект (Then)


отношение(A→B) = доверие(A→B) + (вес_статуса(B) − вес_статуса(A)) + [[Оценить возраст персонажа]](возраст B) + риторика(B) + благосостояние(B)   // временно сырое; позже — оценка через трейты + [[Оценить факты о персонаже]](A оценивает факты о B)


# Пишет (State)

— или только UI (нигде не кэшируется)

# Пример

Игрок открыл сводку купца: считают, как купец относится к игроку. Доверие купца к игроку 40, статус игрока ниже, но купец знает факт «даёт в долг» и сам щедрый → отношение теплее, чем у незнакомца.

# Принадлежит системе

Нет (общая механика социального домена)
