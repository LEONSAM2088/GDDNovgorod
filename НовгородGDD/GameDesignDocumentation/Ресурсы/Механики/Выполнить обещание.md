#Механика 

# Зачем

Отметить выполнение обязательств стороной и усилить доверие к ней.

# Условие (When)

Сторона A выполнила свои обязательства по контракту до истечения срока (или в срок).

# Читает (State)

- контракт: вес обязательств A = W
- [[Уровень доверия к персонажу]]: текущее доверие B→A = C (1…100; если 0 — считать C = 1, чтобы не делить на ноль)

# Эффект (Then)

Прирост доверия B к A:

```
delta = W * (1 - C/100)
```

Чем выше уже кредит доверия C, тем меньше бонус за очередное выполнение (насыщение).

# Пишет (State)

[[Уровень доверия к персонажу]] B→A: `C = min(100, C + delta)`

# Пример

W = 20, C = 50 → delta = 20 * 0.5 = 10 → доверие становится 60.
