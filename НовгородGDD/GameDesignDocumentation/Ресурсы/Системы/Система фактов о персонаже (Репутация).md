#Система

# Зачем:  
Чтобы при взаимодействии персонажей у каждого копилась [[Память (знание о других)|память]] фактов о других, факты передавались (слухи), а оценка фактов через [[Черты характера персонажа|трейты]] давала [[Репутация|репутацию]] — бонус/штраф в социальных проверках.

# Обещание игроку:

"Мои дела оставляют ярлыки/факты. Разные люди по-разному на них реагируют и делятся ими между собой. Чем лучше обо мне знают «нужное», тем легче новые знакомства в нужном кругу."

# State — что хранится, используется и меняется

- `D` = [[Игровой персонаж (Chapter)|Действующий персонаж]]
- `C` = [[Игровой персонаж (Chapter)|Свидетель]]
- `Cs` = {C1…Cn} — множество свидетелей

| Объект(ы) | Данные |
| --------- | ------ |
| любой персонаж | [[Память (знание о других)]] |
| D, свидетели | [[Статус (персонажа)]] |
| оценивающий | [[Черты характера персонажа]] |

# Rules — правила изменения

1. Персонаж стал свидетелем действий другого → [[Запомнить поступок (свидетель)]]
2. Игрок или NPC хочет передать правдивый или ложный факт о ком-то → [[Передать знание о факте (пустить слух)]]
3. Когда NPC инициирует общение с другим NPC, они делятся известными фактами → [[Передать знание о факте (пустить слух)]]  
   *(пока упрощение: «делятся всеми»; позже — фильтр по доверию/общительности)*
4. Когда персонаж обновляет [[Статус (персонажа)]], все NPC узнают этот факт безусловно, пишут в память и при необходимости пересчитывают оценку → пока логика в этом правиле; отдельную механику «публичный статус» можно вынести позже
5. Когда нужна численная репутация B в глазах A → [[Оценить факты о персонаже]]

# Входы

Читает / использует:
- смена [[Статус (персонажа)]]
- исходы обещаний / поступков (как повод для фактов) — из [[Система обещаний]] и других действий
- [[Уровень доверия к персонажу]] (при передаче слуха режет conf)

# Выходы

Пишет / отдаёт:
- [[Память (знание о других)]]
- число R из [[Оценить факты о персонаже]] → читают [[Узнать личное отношение]], [[Система обещаний]] (холодный старт сделки)

# Dynamics — что возникает в игре из правил

- В одном круге «хороший кузнец», в другом «убийца холопа» — разные реакции.
- Слухи разъезжаются: часть города знает, часть нет.
- После публичной сделки с «плохим» растёт риск ярлыков у свидетелей.
- Игрок целенаправленно качает имя в нужной аудитории, а не «репутацию вообще».

# UI / Player-facing - что видит игрок

- тон и ветки при первой встрече («слышал о тебе…»)
- готовность говорить / торговать / в союз (до личного доверия)
- отказ контакта на виду (сделка с репутацией)
- разный приём в разных кругах
- (опц.) уровни словами, не числа

# Telemetry / Debug

**Минимальный срез:** A помогает купцу при свидетелях → у купца тег «надёжен»; незнакомый купец с подходящими трейтами — теплее.

**Логировать:** кто какой factId получил, conf, источник (видел / слух).

**Тест:** подстава слухом → тег только у части NPC, не у всех.
