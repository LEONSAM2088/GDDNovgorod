#Система

# Зачем:  

Чтобы заключать устные или узаконенные договоры, выполнять обещания до срока и рассчитывать на выполнение обещаний других.

# Обещание игроку:

Я могу пообещать и/или взять обещание с другого персонажа для достижения целей.

# Состояния (State)

| Объект | Состояние | Пример |
| ------ | --------- | ------ |
| Персонаж | [[Уровень доверия к персонажу]] | 0…100, исходящее A→B |
| Контракт | свойства | устный/узаконенный, срок |
| Контракт | обязанности сторон | A обещает X (вес W), B обещает Y |
| Персонаж | [[Черты характера персонажа]] | из словаря трейтов |

# Правила

1. Стороны хотят договор → [[Заключить обещание (договор)]]
2. При низком личном доверии к порогу сделки добавляется [[Репутация]] через [[Оценить факты о персонаже]] (см. механику заключения)
3. Сторона выполнила обязательства → [[Выполнить обещание]]
4. Сторона сорвала обязательства → [[Нарушить обещание]]

# Входы

- [[Оценить факты о персонаже]] / память (холодный старт, мало доверия)
- намерение игрока/NPC заключить или закрыть договор

# Выходы

- [[Уровень доверия к персонажу]]
- (позже) факты о надёжности → [[Система фактов о персонаже (Репутация)]]
- UI: список обязательств, срок, риск

# Dynamics

Пока можно не заполнять. Ожидаемо: повторные выполненные мелкие сделки копят доверие с убывающей отдачей; один срыв бьёт сильнее нескольких выполнений.

# UI / Player-facing

- создать / принять договор
- видеть срок и вес обязательств
- уведомление: выполнено / сорвано, изменение доверия словами

# Telemetry / Debug

**Минимальный срез:** договор W=20 при C=40 → после выполнения C растёт по формуле `W*(1-C/100)`.

**Логировать:** contractId, стороны, W, C до/после, исход.

**Тест:** срыв W=10 снимает 20 доверия; выполнение при C=100 почти не даёт бонуса.
