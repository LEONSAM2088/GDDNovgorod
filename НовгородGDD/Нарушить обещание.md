#Механика 

# Зачем

Наказать за срыв обязательств: сильнее ударить по доверию, чем даёт выполнение.

# Условие (When)

Сторона A не выполнила обязательства до конца срока (или отказалась / обманула).

# Читает (State)

- контракт: вес обязательств A = W
- [[Уровень доверия к персонажу]]: доверие B→A = C

# Эффект (Then)

Штраф к доверию B к A:

```
delta = W * 2
```

(Опционально позже: записать факт «не держит слово» через [[Запомнить поступок (свидетель)]] / систему фактов.)

# Пишет (State)

[[Уровень доверия к персонажу]] B→A: `C = max(0, C - delta)`

# Пример

W = 10 → штраф 20 к доверию B→A.
